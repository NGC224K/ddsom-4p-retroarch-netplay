2. 방 참가 또는 방 만들기

  1. 패드가 있다면 먼저 연결합니다.
  2. DND-START.bat을 더블클릭합니다.
  3. 다른 사람의 방에 들어가려면 [1] 방 참가를 선택하고 방장에게 받은 주소와 별명을 입력합니다.
  4. 내 PC로 방을 만들려면 [2] 방 만들기를 선택합니다. 화면에 표시된 공인 IPv4를 친구에게 개인 메시지로 알려줍니다.
  5. 방을 만든 기기가 P1이고, 이후 접속 순서대로 P2/P3/P4가 됩니다.
Windows에서 방을 만들 때: Windows 방화벽에서 개인 네트워크 액세스를 허용하고, 인터넷 친구를 받으려면 공유기에서 TCP 55435를 이 PC로 포트 전달해야 합니다.
Windows 방화벽 창이 뜨면 RetroArch의 개인 네트워크 액세스를 허용하세요. 공용 네트워크는 보통 체크할 필요가 없습니다.

3. 전체화면·해상도·화면비율

고화질 자동 적용: [1] 또는 [2]를 선택하면 선명한 화면 효과가 자동 적용됩니다. 화면이 검게 나오거나 느리면 [6] JOIN 또는 [7] HOST 그래픽 호환 모드를 사용하세요.

게임 중 F를 누르면 전체화면과 창모드가 바뀝니다. 노트북의 기능키와 겹치면 Fn+F를 시도하세요.

메뉴에서 바꾸려면 F1 → Settings → Video로 이동합니다.

Integer ScaleOFF큰 화면에서 검은 여백이 과해지는 것을 방지

5. Xbox·PlayStation·일반 USB 패드

먼저 해 볼 것

  1. RetroArch를 닫습니다.
  2. 패드를 USB로 연결하거나 Bluetooth 연결을 끝냅니다.
  3. DND-START.bat → [5]를 엽니다.
  4. 화면 아래에 configured 또는 패드 이름이 뜨면 자동 인식된 것입니다.

Xbox 패드는 보통 바로 됩니다. PlayStation 패드는 Wireless Controller, DualSense 또는 DualShock 이름으로 보일 수 있습니다. 일반 USB 패드는 직접 매핑해야 할 수 있습니다.

직접 버튼 맞추기

Settings → Input → RetroPad Binds → Port 1 Controls에서 Device Index를 자기 패드로 고르고 Set All Controls를 실행합니다. 끝나면 Save Controller Profile을 선택합니다.

설정을 바꾼 뒤에는 저장하세요.
Main Menu → Configuration File → Save Current Configuration을 선택해야 다음 실행에도 변경 내용이 남습니다. 단, Netplay·Core·Drivers 설정은 바꾸거나 저장하지 마세요.
게임 버튼이 마음에 들지 않을 때는 게임 실행 후 F1 → Quick Menu → Controls → Port 1 Controls에서만 바꾸세요. 전체 메뉴 조작까지 뒤집히는 것을 막을 수 있습니다.

6. P2 / P3 / P4 배정 확인

이 패키지는 자동 배정 방식입니다.
Windows 또는 Bazzite에서 방을 만든 사람=P1 → 첫 번째 접속자=P2 → 두 번째=P3 → 세 번째=P4

친구 셋은 통화하면서 한 명씩 접속하세요. 먼저 P2 친구가 게임 화면을 확인하고, 그다음 P3, 마지막 P4가 들어옵니다.

게임의 캐릭터 선택 화면이나 코인 입력으로 자기 자리인지 확인합니다. 각자 Coin/Select를 한 번 누른 뒤 Start를 누릅니다.

자리가 꼬였으면: 누구도 Request Device 설정을 켜지 말고, 친구 셋이 모두 종료한 뒤 P2 → P3 → P4 순으로 다시 들어오세요. 중간에 관전자로 들어간 사람은 Netplay → Request to Play를 선택합니다.

7. 음량과 기본 소리 설정

+ / 숫자패드 +는 음량 올리기, -는 내리기, F9는 음소거입니다. 메뉴에서는 Settings → Audio → Volume Gain (dB)를 조절합니다. 0 dB가 기본입니다.

게임 소리가 통화 소리를 덮으면 -6 dB 정도부터 시도하세요. 소리가 끊길 때 Audio Driver나 Latency는 바꾸지 말고 먼저 다른 앱을 닫으세요.

9. 초보자용 문제 해결

“ddsom.key가 없습니다” 또는 “ROM 불일치”가 나와요

ddsom.key는 별도 CPS-2 BIOS가 아니라 현재 FBNeo용 ddsom ROM 세트의 일부입니다. 현재 코어에는 ZIP 내부의 ddsom.key(CRC-32 541e425d)가 필요합니다. 본인이 보유한 원본에서 현재 FBNeo에 맞는 완전한 세트를 다시 준비하세요. 파일 하나만 인터넷에서 따로 구해 덧붙이지 마세요. 그다음 [4] ROM 검사에 표시된 SHA-256 전체를 방장과 비교합니다.

방에 접속되지 않아요

  1. 주소의 앞뒤 공백과 숫자를 확인합니다.
  2. 방장이 먼저 HOST를 켰는지 확인합니다.
  3. 모두 같은 패키지와 ROM인지 확인합니다.
  4. VPN을 사용 중이면 잠시 끄고 재시도합니다.
  5. 방장은 TCP 55435 방화벽과 공유기 포트 전달을 확인합니다.

계속 실패하면 logs\last-join.log를 방장에게 보냅니다.

패드가 안 잡혀요

  1. RetroArch를 완전히 닫고 패드를 뽑았다 다시 꽂습니다.
  2. Windows의 “게임 컨트롤러 설정”에서 버튼이 반응하는지 확인합니다.
  3. Steam이 켜져 있다면 종료한 뒤 다시 시도합니다.
  4. Settings → Input → RetroPad Binds → Port 1 Controls → Device Index에서 패드를 고릅니다.

키가 꼬였거나 메뉴 조작도 이상해요

RetroArch를 닫고 시작 도우미를 다시 엽니다. 이 패키지는 종료할 때 전체 설정을 덮어쓰지 않도록 되어 있습니다. 그래도 계속되면 패키지를 새 폴더에 다시 압축 해제하고 ROM만 옮기는 것이 가장 빠릅니다.

게임이 바로 닫혀요

logs\last-join.log 마지막 부분을 방장에게 보냅니다. ROM 세트가 현재 FBNeo와 맞지 않을 가능성이 큽니다.

10. 건드리지 않아도 되는 설정

아래 항목은 방장이 문제 해결을 요청하기 전에는 바꾸지 마세요.

  • Core Updater / Update Installed Cores — FBNeo 버전이 달라져 접속이 깨질 수 있습니다.
  • Netplay Request Device 1~4 — 한 명이라도 켜면 자동 P2/P3/P4 배정이 꺼집니다.
  • Latency의 Run-Ahead / Rewind — 동기화 문제를 만들 수 있습니다.
  • Drivers의 Video, Audio, Input, Controller 드라이버
  • Core Options와 DIP Switch — 모든 사람의 게임 상태가 달라질 수 있습니다.
  • Save State / Load State / Cheats / Fast Forward — Netplay 중 사용 금지.
  • cores\fbneo_libretro.dll, config\retroarch.cfg 파일 교체
바꿔도 되는 것: 창/전체화면, 음량, 자기 키보드·패드 버튼, 별명.
